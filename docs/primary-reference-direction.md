# O.C. Tanner UI / Avathon business context

This direction supersedes the globe, the dark graphite homepage, and the earlier construction-first statement. Primary UI reference: https://www.octanner.com/. Business-context reference: https://avathon.com/.

The reference was opened in Chrome at 1440×1000. Computed primary-reference type: Gotham SSm, H1 84px/92.4px, weight 500, -3.6px tracking; H2 56px/61.6px, weight 500, -2.8px; service titles 32px/35.2px. Navigation sits 32px below the top and 56px from the sides, in an 88px black bar. The implementation follows those dimensions, a full-viewport film hero, sentence-case display copy, rounded rectangular buttons, and large photographic cards on light editorial sections.

**Font boundary:** the project has the self-hosted OFL Outfit font. It is a substitute, not Gotham SSm. Exact font matching requires a Gotham SSm webfont license and files from the owner. No proprietary font was copied from the reference.

Avathon informs the sequence from operational context to usable action and clear responsibility. BundleBoB is presented as an engineering service, not Avathon's platform. Its own copy covers practical AI, custom software, connected systems, and an FDE working directly with the client. Thirteen industries are represented. Construction appears as an explicitly synthetic demonstration; no customer proof or measured results are invented.

Removed: WebGL globe, pinned scroll stages, layered 3D process diagram, decorative scroll drift, and the “don't hire us” block. The service carousel supports buttons, keyboard, and native touch scrolling. Page anchors use native smooth scrolling, disabled for reduced motion.

New hero film: `business-in-motion.mp4`, 20 seconds, silent 1080p H.264. The edit begins with engineering work, then operational scale, field collaboration, and connected infrastructure. It is an authored edit of licensed real stock footage, not an AI-generated video. Sources and reproduction are in `media-sources.md`. Playback remains optional on mobile and for reduced-motion/data-saving visitors.

The 20 existing pages remain available. This is a local preview, not a production deployment. Contact still prepares a downloadable inquiry until a verified delivery destination is configured.
